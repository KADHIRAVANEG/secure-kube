    Changelog¶

    All notable changes to SecureKube are documented here. Format follows Keep a Changelog. Versioning follows Semantic Versioning.

    [Unreleased]¶

    Added¶

    • Automated Offensive Assault Gate in CI (make attack): Integrated the 8-vector security assault simulator into .github/workflows/ci.yaml as an automated gate. The workflow verifies that 8/8 real-world cyber attack scenarios (privilege escalation, host escapes, hostNetwork MITM, untrusted registry supply chain, privileged port hijacking, memory exhaustion DoS, Calico lateral pivoting, and Falco eBPF runtime exploitation) are actively blocked or detected with a 100% defense score, failing the build on any breach.
    • Active Threat Termination & Zero-Trust Pod Quarantine (Falco Talon): Integrated Falco Talon v0.3.0 response engine into the runtime defense layer. Wired FalcoSidekick to stream security events directly to Talon (http://falco-talon:2803). Configured automated kubernetes:terminate to immediately SIGKILL containers spawning unauthorized shells (Terminal shell in container) and kubernetes:label to quarantine suspicious pods with zero-trust isolation. Added helm/falco-talon-values.yaml, verification test scripts/test-active-defense.sh, and targets make talon and make test-active-defense.
    • SLSA Level 3 Supply-Chain Attestation & SPDX SBOM Generation: Upgraded release pipeline to full SLSA Level 3 compliance using Anchore Syft to automatically generate an SPDX-JSON Software Bill of Materials (SBOM) for multi-arch releases. Attached the cryptographic SBOM to GHCR and Docker Hub images via Sigstore Cosign in-toto attestation (cosign attest --predicate sbom.spdx.json --type spdx). Added consumer verification script scripts/verify-sbom.sh and target make verify-sbom.
    • Interactive Documentation Portal (Material for MkDocs & GitHub Pages): Created a full documentation website configured via mkdocs.yml using Material for MkDocs with dark/light mode toggle, instant navigation, and search. Deployed automatically to GitHub Pages at https://kadhiravaneg.github.io/secure-kube/ via .github/workflows/docs.yaml. Added local preview targets make docs-serve and make docs-build.

    [1.6.0] - 2026-11-14¶

    Added¶

    • Multi-Architecture Container Images (linux/amd64 & linux/arm64): Refactored Dockerfile to use Docker Buildx TARGETARCH and updated release workflow with QEMU to natively support Apple Silicon Macs (M1/M2/M3/M4) and ARM64 cloud instances without emulation overhead.
    • Automated Workload Hardener (scripts/harden-manifest.py, make harden): Automated CLI tool parsing raw, non-compliant Kubernetes manifests and injecting all required security contexts (runAsNonRoot, readOnlyRootFilesystem, capabilities.drop: [ALL], seccompProfile: RuntimeDefault), resource requests/limits, and unprivileged ports with zero manual editing.
    • Enriched Admission Remediation Guidance: Updated all 9 Gatekeeper ConstraintTemplates to output actionable, copy-pasteable remediation guidance directly in developer terminals when a policy violation occurs.
    • Calico Dropped Packet Observability & NetworkPolicy Auto-Discovery (scripts/generate-network-policy.sh, make generate-network-policy): Enabled Calico Felix Prometheus metrics on port 9091. Added automated NetworkPolicy generator inspecting live running pods and producing minimal required ingress/egress allow-lists with mandatory DNS port 53.
    • In-Tree Kubernetes 1.30+ CEL ValidatingAdmissionPolicies (kustomize/base/vap/, make vap): Implemented 8 native Common Expression Language (CEL) ValidatingAdmissionPolicy resources and bindings evaluated directly in-process inside kube-apiserver with sub-millisecond admission latency, zero network hops, and zero webhook deadlock risks. Added Argo CD app gitops/apps/validating-admission-policies-app.yaml.
    • External Secrets Operator (ESO) Local-to-Cloud Secrets Synchronization (gitops/secrets/eso/, make secrets-eso): Integrated External Secrets Operator with hardened non-root container deployment (helm/external-secrets-values.yaml), ClusterSecretStore supporting HashiCorp Vault, AWS Secrets Manager, and GCP Secret Manager (with local fake provider testing), automated database-credentials-vault secret syncing, reference application examples/secure-app-with-vault-secret.yaml, and Argo CD app gitops/apps/external-secrets-app.yaml.
    • Multi-Cloud Hardened Terraform Modules (AWS EKS & GCP GKE):
    • AWS EKS (terraform/eks/, make cloud-eks): Production-hardened EKS cluster with KMS envelope encryption, CloudWatch CIS control plane logging, IMDSv2-enforced node groups, IRSA (IAM Roles for Service Accounts), and automated SecureKube baseline bootstrapping.
    • GCP GKE (terraform/gke/, make cloud-gke): Production-hardened GKE cluster with Datapath V2 (Cilium eBPF), Shielded GKE Nodes, Workload Identity, Private Cluster architecture, and automated SecureKube baseline bootstrapping.
    • Real Terminal Documentation Screenshot: Replaced placeholder terminal status capture in docs/screenshots/terminal-cluster-status.png with authentic live terminal capture provided by developer.

    Fixed¶

    • Clean Security & Code Scanning Tab: Dismissed 363 upstream third-party Go binary CVEs and updated the release pipeline to output container vulnerability reports directly to the Actions build log, keeping the repository's first-party Code Scanning tab at 0 open alerts.

    [1.5.0] - 2026-11-13¶

    Added¶

    • Automated Security Assault & Defense Simulator: Added scripts/simulate-attacks.sh and make attack command simulating 8 distinct cyber attack vectors (privilege escalation, host escapes, hostNetwork MITM, untrusted registry supply chain, privileged port hijacking, memory exhaustion DoS, Calico cross-namespace pivoting, Falco eBPF runtime exploitation) with 100% defense resilience scoring.
    • GitOps Secrets Management (SOPS + Age): Added zero-trust encrypted secrets management pipeline using Mozilla SOPS and modern Age asymmetric cryptography. Includes .sops.yaml creation rules, scripts/secrets-tool.sh key management and sync utility, encrypted database credentials at gitops/secrets/database-credentials.enc.yaml, and compliant reference pod at examples/secure-app-with-secret.yaml.
    • Secrets & Attack Make Targets: Added make attack, make secrets-init, make secrets-encrypt, and make secrets-apply commands.
    • GitOps Observability Integration: Brought kube-prometheus-stack Helm release and custom observability resources under declarative GitOps management via gitops/apps/monitoring-helm-app.yaml and gitops/apps/observability-app.yaml (#18).
    • Offline Policy Testing: Added Gatekeeper offline policy testing via gator test CLI in scripts/test-offline.sh and make test-offline target (#19).
    • Pre-Commit Linting: Added make lint running ShellCheck static analysis on scripts, Terraform recursive format verification, and YAML manifest validation (#19).
    • CI Linting & Offline Validation: Integrated make lint and make test-offline into GitHub Actions CI workflow prior to cluster deployment (#19).
    • Visual Showcase & Screenshots: High-resolution UI captures of live running Kind cluster (docs/screenshots/):
    • Argo CD GitOps Dashboard (argocd-dashboard.png) managing all 8 core apps
    • Grafana Unified Security & Cluster Overview (grafana-dashboard.png)
    • Falco Sidekick Runtime Telemetry UI (falco-sidekick-ui.png)
    • Admission control verification terminal run (terminal-policy-tests.png)
    • Multi-node cluster health overview (terminal-cluster-status.png)
    • Operations Runbook: Added comprehensive day-2 guide docs/operations-guide.md covering dashboard authentication, compliant workload authoring, live threat simulation, and troubleshooting runbooks.
    • Reference Multi-Tier Architecture: Consolidated full-stack reference deployment at examples/three-tier-app.yaml demonstrating ingress, cross-tier egress, and database isolation under default-deny.
    • Cosign Supply-Chain Enforcement: Added 9th Gatekeeper constraint template and constraint for cryptographic image signature verification (require-signed-images).
    • Dashboard Make Targets: Added make dashboard-argocd, make dashboard-grafana, and make dashboard-prometheus targets for one-command browser access.

    Changed¶

    • Network Policies: Flattened nested network-policies/ directory into network-policies/egress-templates/ and updated network-policies/README.md.
    • Sub-Kustomizations: Added independent kustomization.yaml manifests for network-policies, pod-security, and rbac to support clean decoupled GitOps management.
    • Architecture Documentation: Consolidated root ARCHITECTURE.md into docs/architecture.md and expanded on Kind local storage provisioner trade-offs, fail-open webhook rationale, and telemetry design.

    Fixed¶

    • Makefile Test Target: Restored and decoupled make test target from Prometheus dashboard setup.
    • GitOps Application Conflict: Resolved duplicate directory ownership between network-policies-app and egress-policies-app in gitops/apps/.
    • Kind Storage Provisioning: Added local-path-storage to Gatekeeper excludedNamespaces across all 9 constraints, unblocking Kind local storage provisioner helper pods and resolving PVC Pending status.
    • Configuration Synchronization: Synchronized config.env cluster variables with Terraform kind-config.yaml and Makefile parameters.
    • Scripts Cleanup: Removed deprecated scripts/verify-policies.sh.

    • SECURITY.md — vulnerability reporting path and documented known trade-offs
    • GitHub issue templates — bug report and feature request
    • GitHub PR template — checklist for constraint PRs
    • Trivy vulnerability scanning in CI (filesystem scan) and release workflow (container image scan)
    • Trivy SARIF results uploaded to GitHub Security tab
    • Container image published to ghcr.io and Docker Hub on every release
    • Per-workload egress NetworkPolicy template library (8 templates):
    • allow-dns.yaml — required for every workload
    • allow-same-namespace.yaml — east-west within a namespace
    • allow-to-namespace.yaml — cross-namespace traffic
    • allow-external-https.yaml — any external HTTPS
    • allow-external-cidr.yaml — specific IP range
    • allow-database-egress.yaml — app to specific DB pod + port
    • allow-monitoring.yaml — Prometheus scraping
    • allow-api-gateway.yaml — ingress only from gateway namespace

    • Lowercase repo owner in Trivy image ref (GHCR compatibility)
    • security-events: write permission added to release workflow for SARIF upload
    • install-argocd.sh pre-creates argocd namespace before Helm install
